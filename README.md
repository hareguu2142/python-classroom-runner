# 파이썬 교실

설치 없이 브라우저에서 Python 코드를 작성하고 실행하는 수업용 실습기입니다. Python은 [Pyodide](https://pyodide.org/)를 통해 학생의 브라우저 안에서 실행됩니다.

## 주요 기능

- Python 3 코드 작성 및 실행 (문법 색상, 괄호 짝 표시, 콜론 뒤 자동 들여쓰기)
- 실행 중에도 `print()` 출력이 바로바로 표시됨
- 오류 메시지와 함께 자주 하는 실수에 대한 한국어 도움말 표시
- 한 줄씩 실행하며 다음 실행 줄과 변수 확인 (방금 바뀐 변수 강조)
- 편집기 커서가 놓인 줄까지 실행
- 한 줄 뒤로 되돌리기
- `input()` 호출 시 터미널에서 바로 입력
- 로컬 TXT·CSV 파일을 불러와 Python의 `open(...).read()`로 읽기
- `.py` 파일 열기와 내려받기
- 무한 반복 등 장시간 실행 중지
- 밝은 테마(기본)와 어두운 테마
- 예제 코드 제공 (비상교육 고등 정보 Ⅲ-2 단원 1~4차시 수업 PPT의 프로그램 예제 포함)
- 작성 중인 코드를 브라우저에 자동 저장
- 모바일·터치 화면 대응

## 단축키

| 동작 | 단축키 |
| --- | --- |
| 전체 실행 | `Ctrl` + `Enter` |
| 한 줄 실행 | `F10` 또는 `Alt` + `↓` |
| 한 줄 뒤로 | `Shift` + `F10` 또는 `Alt` + `↑` |
| 커서까지 실행 | `Ctrl` + `F10` 또는 `Alt` + `→` |
| 들여쓰기 / 내어쓰기 | `Tab` / `Shift` + `Tab` (여러 줄 선택 가능) |

F10 키가 없는 크롬북에서는 `Alt` 조합을 사용하세요.

## 로컬 실행

ES module과 Web Worker를 사용하므로 HTML 파일을 직접 열지 말고 간단한 웹 서버로 실행합니다.

```powershell
python -m http.server 8000
```

브라우저에서 <http://localhost:8000>을 엽니다.

## TXT 파일 읽기

편집기 위 **파일 → TXT 추가**로 파일을 선택한 뒤, 선택한 파일 이름을 그대로 사용해 읽습니다.

```python
with open("sample.txt", "r", encoding="utf-8") as file:
    content = file.read()

print(content)
```

여러 TXT 파일을 한 번에 불러올 수 있으며 파일은 브라우저 안에서만 사용됩니다. 새로고침하면 불러온 파일은 사라집니다.

## 배포

별도의 백엔드 없이 GitHub Pages에서 동작합니다. 최초 로딩(Pyodide, CodeMirror)과 일부 패키지 사용에는 인터넷 연결이 필요합니다.

## 예제 추가하기

예제는 [examples.js](./examples.js)에 단원별로 정리되어 있습니다. `files`에 파일 이름과 내용을 넣으면 예제를 고를 때 그 파일이 함께 추가됩니다.

기후 통계 예제(3-2-4)는 `대한민국 기후 통계.csv` 파일을 **파일 → TXT·CSV 추가**로 먼저 추가해야 실행됩니다.

## 디버거 동작 방식

GitHub Pages의 정적 호스팅 환경에서도 한 줄 뒤로 되돌리기를 제공하기 위해 코드와 입력 이력을 처음부터 빠르게 재생합니다. 재생할 때 난수는 같은 값이 나오도록 고정하고, 작업 폴더의 파일은 실행 시작 시점으로 되돌립니다. 네트워크 요청이나 현재 시각처럼 바깥 상태에 의존하는 코드는 되돌린 결과가 달라질 수 있습니다.
